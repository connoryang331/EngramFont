# 节点类型即几何：降格必须改线段与手柄，Alt+双击才是"只改标志"

## 背景

[ADR-0009](0009-squircle-g2-nodes.md) §4 立了一条原则：**图标不得声称几何没有的
东西**——G2 解不出来就不落标志，比不响应更糟。但这条原则当时只覆盖**升格到 squircle
的求解失败**，没有覆盖**降格**。

现行降格实现（`toggleSmooth` 只翻 `pointTypes`，`advanceNodeKind` 的 corner 目标
调 `toggleSmooth(path, idx, ON_CURVE)`）的后果是：把一个 squircle 节点双击成 corner，
**线段和手柄一个坐标都不动**——轮廓仍是被 G2 解修好的弯曲接缝，角点方块图标挂在
一个曲率连续的地方。

用户 600×400 矩形四连双击后的原话：

> **"corner，smooth，squircle 是线段的状态变换，线段，手柄都要随着状态图标改变而
> 改变。如果不想改变手柄和线段，那就用 alt+双击。"**

即：**类型 = 几何状态**，而不是贴在几何上的标签；"我不想动几何"要另给出口，而不是
作为默认值。

被这条要求牵连的现实（本轮实测与代码事实）：

- 一次转曲会插入**最多 4 个控制点**（自己的近手柄 ×2 + 两条邻段的远端手柄 ×2），
  其中一半在几何上属于**邻居节点的侧**——所以"只动这个节点"在数据上不是局部操作；
- 上游 `alignHandles` → `alignHandleAlongDirection` 末尾 `vector.roundVector`，对
  **已经共线**的手柄也取整，会把 [ADR-0010](0010-node-slide-g2.md) 刻意写入的分数
  坐标钳回整数，曲率跳变从 0.07% 弹回 1.1%。

## 决策

### 1. 不变量：图标不得声称几何没有的东西（扩展到全部三档）

这是 ADR-0009 §4 的同一条原则，作用域扩到 corner / smooth / squircle。形式化为：

> **每个手势之后，被触碰的轮廓上每一个节点都必须自洽** —— 标志描述的东西，
> 几何必须真的满足。

- corner：两侧邻边是直线（曲率 0），且两侧切线不共线（真折角）；
- smooth：两侧切线共线（曲率向量平行，方向可同可反）；
- squircle：曲率向量**等大且同向**。

### 2. corner 降格**真的变成角**

过节点的两条邻边被重建为直线，手柄落在弦上：

```
far ← t = 1/3 → P ← t = 2/3 → next
只有一个手柄时：取中点（h = (far + P)/2 或 (P + next)/2）
```

于是两条邻边都成为直线，**折角让给邻居节点**——因为直边是硬约束，被钉直的边另一端
只能是折角（或本来就是折角）。

- **手柄保留而不删除**：一个控制点可能是**邻段共享**的，删掉会静默拉直用户没碰的边；
  保留也让三档循环可逆（再升格时手柄已就位，不必重建）；
- **坐标不取整**：取整会留下微小但真实的曲率——与 `applySquircleAtPoint` 里同款的坑。

### 3. smooth 升格**真的掰弯直线**

`toggleSmooth` pass 3 从"两侧各有各的规则"改为**一条规则覆盖两侧**：把每个近手柄
**旋转到共享切线、保持各自长度**。

- 直线侧：直线的 1/3 长度天然满足这个旋转，于是**直线被掰弯**（这正是 ADR-0006
  要的"双击方形节点变成杏仁形，线也跟着弯"）；
- 曲线侧：退化为上游 `alignHandles` 的**保长旋转**，与上游行为一致。

一条规则 ⇒ G1 落在**几何**里，而不只是图标里。

**已共线且本来就是 smooth 时跳过写入**：否则会把 ADR-0010 的 G2 解刻意写入的分数
坐标取整（曲率跳变 0.07% → 1.1%）。判据是无量纲共线度 `|in×out|/(|in||out|) < 1e-4`。

### 4. Alt+双击 = 只改标志

`opts.geometry === false`：不碰任何坐标，只翻 `pointTypes`。这是用户要的
**"我只想换图标"**出口——默认行为是改几何，想要保守行为必须显式按住 Alt。

### 5. 邻居修复：沿轮廓走查 + 一次不变量扫描 + 量出来的几何说了算

一段的**远端手柄属于邻居**，所以把一边钉直会改动邻居的切线。三段式收尾：

1. **有界走查**：沿轮廓向外走，**只修我们确实弄坏的节点**，遇到第一个自洽节点就停
   （不递归、不做全轮廓重扫）；
2. **一次不变量扫描**：`enforceContourHonesty()`，最多 3 轮，修完自洽即止；
3. **不信 status，信写完之后量出来的几何**：`nodeFlagsAreHonest()` 复核
   **曲率向量同向 + 大小相等 + G1 共线**；复核不过就**撤标志**；角点被掰弯则重新钉直。

修邻居时若一侧已被相邻角点钉成直线，则**两个手柄都放在那条线上**——否则会把角点
刚钉直的边重新掰弯。

### 6. 线↔曲线重新求解时的写回**只写曲线侧**

求解器对直线侧返回的是"**别动**"的哨兵值（[ADR-0009](0009-squircle-g2-nodes.md) §3：
零曲率必须落在曲线侧）。旧代码两边都写，会把直线侧手柄搬到远端手柄的位置上——
一次直线侧的手柄凭空平移。现按 `kind` 分派：只写允许写的那一侧。

### 7. 不可解时的诚实结果

邻居的 `SQUIRCLE_FLAG` 会被**撤掉**（降为 smooth）：共享边被钉成直线后，G2 在数学上
不再成立。**宁可少一个标志，不留一个撒谎的图标**（§1 的直接推论）。

## 理由

1. **类型是状态，不是标签**：用户在同一句话里给了判据（"是线段的状态变换"）和出口
   （"不想改变就用 alt"）。默认改几何、把保守行为显式化，比反过来更符合直觉：
   用户双击一个方块，期望的是"这个角变成圆滑的角"，而不是"图标换了、线还是尖的"。
2. **不改几何的降格会让不变量失效**：corner 方块 + 弯曲接缝 = 图标在撒谎，而这是本仓
   早就写下的原则（ADR-0009 §4）。
3. **手柄保留而非删除**：Fontra 的控制点属于**段**（每段 0/1/2 个），一个控制点可能
   同时是邻段的形状要素。删除是破坏性且难以预测的；保留 + 旋转是可逆的。
4. **量几何而不是信 status**：`status` 描述的是"求解器想做什么"，而用户看到的是
   "几何变成什么样"。只有写完之后重新测曲率，才能保证不变量。
5. **Alt 出口而非"默认保守"**：如果默认是只改标志，用户就必须先学会按住 Alt 才能得到
   想要的效果——这与 Glyphs/FontLab 的默认（eager convert，双击）相反。

## 被否决的方案

- **只翻标志的降格**（即改前的现状）：用户明确否掉；且与 §1 的不变量直接冲突。
- **给节点做形状存档**（记住原形状，降格时回滚）：手柄在邻段间共享、且用户会在
  中途继续编辑，回滚要么不完整（只记节点不记段），要么**静默丢弃后续编辑**。
- **递归修邻居**（一个节点变了就无限递归修所有受影响的）：实测会波及其他用户没碰的
  边；改为**有界走查 + 固定轮数扫描**后，修复范围严格限制在"我们确实弄坏的节点"。
- **默认只改标志、Alt 改几何**：把"想要结果"和"想要保守"的主次颠倒，且与两家默认相反。

## 后果

- 三档手势（普通双击循环 / Shift+双击直达 / **Alt+双击只改标志**）语义统一为
  "类型 = 几何"，实现集中在 `fontra-core/src/path-functions.js`
  （`toggleSmooth` pass 3 的保长旋转、`advanceNodeKind`、`enforceContourHonesty`、
  `nodeFlagsAreHonest`）；
- corner 降格会**真的变直**，并把折角推给邻居——邻居可能被连带降级（标志撤回）；
- 手柄永不删除，永不取整；
- G2 求解的移动自由度见 [ADR-0010](0010-node-slide-g2.md)（沿切线微移，取代价
  更小者）；两篇配套阅读：一篇管"升格能修多好"，一篇管"降格必须改多少"。

## 验证

- `npm run --workspace src-js/fontra-core test`
  → squircle 测试 **136 pass / 0 fail**（含新增 **T10 降格成真角 + Alt 只改标志**、
  **T11 邻居无撒谎**）；全包 **1215 passing** / 0 failing
- `npx playwright test` → **35/35**
- `qa/verify-squircle-gesture.mjs` → **7/7**
- `qa/measure-cycle.mjs`、`qa/audit-honesty.mjs`（本轮实测脚本，保留作回归证据）
- 实测（600×400 矩形，右上角，四连双击）：corner→smooth 曲率 **4.74e-3 / 7.12e-3**
  （跳变 33.4%）；smooth→squircle 节点滑 16.5、手柄不动、跳变 **0.000**；
  squircle→corner 两侧曲率 **1.99e-18 / 4.13e-18（都是直线）**；
  再 corner→smooth 又弯回 **3.87e-3 / 7.94e-3**；**按住 Alt 时四次手势几何一次都不变**
- 多点互扰实测：四角全 squircle 后降格一角 → 被降格角两侧皆直，**两个邻居自动降为
  smooth（标志撤回）**，对角仍 squircle 且 G2 精确
