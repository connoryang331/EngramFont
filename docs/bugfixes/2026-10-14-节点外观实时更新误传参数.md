# BUG-004 · 节点外观"实时更新"其实从未生效

日期：2026-10-14  状态：fixed

## 现象

设置页改节点颜色/尺寸，编辑器画布不即时变，要重开字形上下文才生效
——而 R4-T4.25 的记录里写的是"实时重建可视化图层"。

## 根因

`src-js/views-editor/src/editor.js` 的实时监听回调把参数传错了：

```js
themeController.addKeyListener(key, () => {
  applyNodeAppearanceSettings(visualizationLayerDefinitions);  // ← 数组当 model 传
  ...
});
```

旧实现里 `model.nodeAppearanceCustom` 对数组取值是 `undefined` → 走 else 分支
"恢复内置默认"——等于**每次键变化都把图层重置回默认**，实时更新名存实亡。

## 修复

传 `themeController.model`；顺带按 ADR-0002 删除 `nodeAppearanceCustom` 分支
（自定义外观无条件应用），监听键列表同步移除该键。

## 验证

Playwright：设置页改 `nodeSmoothSize` = 14 → `localStorage["engramfont-nodeSmoothSize"]`
= "14"（`qa/verify-slant.mjs` 的 sizeEditPersisted / localStorage 检查）；
画布侧由编辑器重开上下文后节点样式与设置一致（R4-T4.25 既有验证路径）。

## 备注

教训：**监听器回调的参数要过一眼类型**——传错对象不报错、只是静默走错分支，
比崩溃更难发现。
