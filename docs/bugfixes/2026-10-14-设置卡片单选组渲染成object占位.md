# BUG-001 · 设置卡片单选组渲染成 "[object HTMLDivElement]"

日期：2026-10-14  状态：fixed

## 现象

应用设置 → Theme settings 卡片里，单选组（Automatic/Light/Dark）的位置显示一行文本
`[object HTMLDivElement],[object HTMLDivElement],[object HTMLDivElement]`（用户截图）。

## 根因

`src-js/fontra-webcomponents/src/simple-settings.js` 的 `render()`：为统一样式把所有行
包进一个 `div.settings-list`；而 `radio` 渲染器返回的是**行数组**（每个选项一行）。
`createDomElement` 用 `element.append(children)` 挂子节点——把数组传进去会被
`toString()` 成一行文本。

旧实现没炸是因为 `render()` 的返回值直接交给 `UnlitElement._render()`，那里有
`elements.flat()`；包一层 div 之后 flat 的责任就落到了自己头上。

## 修复

`render()` 里 `.map(...).flat()` 之后再挂载（同一文件一行）。

## 验证

Playwright 打开设置页 Theme settings / Display language / Clipboard 三个卡片：
正文不含 `[object`，radio 文字正常（`qa/verify-v3.mjs` 的
`display-languageObjectString` / `clipboardObjectString` 均为 false）。
