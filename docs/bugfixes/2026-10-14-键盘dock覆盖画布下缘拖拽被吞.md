# BUG-005 · 键盘 dock 覆盖画布下缘，拖拽起点被键帽吞掉

日期：2026-10-14  状态：mitigated

## 现象

e2e/手测在画布下部起手拖拽（y≈710 / 850 @1440×900）完全无响应；一次实测把
dock 的 "s" 键帽当成了画布点击——文本被插入 "s"，随即弹出
"Create a new glyph "s"?" 模态，后续全部输入被模态吃掉。

## 根因

键盘 dock（`keyboard-dock.js`）以浮层覆盖画布底部一大条，键帽可命中。
Playwright/CDP 按**最顶层元素**派发事件——命中 dock 键帽 = 画布收不到
pointerdown，`handleDrag` 根本不会启动（实测 `dragCalls: 0`）。

## 缓解

- **测试侧**（已落地）：拖拽/点击前用 `document.elementsFromPoint` 断言落点是
  `#edit-canvas`；用 `canvasController.setViewBox` 把字形缩放到画布上部
  （留出 dock 带）再交互——模式见 `qa/verify-slant.mjs`。
- **产品侧**（留意项）：dock 拦截画布手势是设计内行为（dock 就是键盘），
  但"落点贴着 dock 上缘"的误触值得在 dock 命中区上再做收窄评估。

## 验证

`qa/verify-slant.mjs`：zoom 后矩形 / 斜向 / 定角三段交互全部跑通（此前 0 响应）。
