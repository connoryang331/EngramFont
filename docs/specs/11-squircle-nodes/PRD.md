# R11 · Squircle 节点（曲率连续 / G2）· 需求文档（PRD）

## 背景

既有节点模型只有两档：

- **corner**（方形）= 无约束；
- **smooth**（眼形）= 一阶连续（G1）：相邻段共享**切线**。

Glyphs App 还有第三档（其手册称 super-smooth）：二阶连续（G2），**曲率**也连续，
因此过渡处不会有"曲率折角"。

> 来源：Glyphs Handbook · Editing Paths · Super-smooth Nodes
> <https://handbook.glyphsapp.com/editing-paths/#super-smooth-nodes>

Glyphs 用两种图标区分该档的两种情形：**五角星**（曲线↔曲线）、
**雨滴**（直线↔曲线）。

## 需求（用户原话）

> "实现类似 glyphs app 的这个功能。但是需要修改一下，图片是 超椭圆图标。
> 不需要五角星。"

> "SUPER_SMOOTH 应该叫做 超椭圆 squircle 而不是 super smooth"

即：**实现 G2 曲率连续节点，但命名与图标都用「squircle / 超椭圆」，不用 Glyphs 的五角星。**

这与本仓既有设计体系一致——[字体设计图例符号系统设计说明](../../idea/字体设计图例符号系统设计说明.md)
早已把「超椭圆点」定位为**曲率连续**的符号，并明确批评五角星是
"纯约定符号、形状与含义无直觉关联"。所以本方案不是偏离 Glyphs，而是**执行既有决策：形状即含义**。

## 目标

1. 节点支持第三档：**squircle**（G2 曲率连续）；
2. 图标为**超椭圆**（squircle），**绝不出现五角星**；
3. 曲线↔曲线：精确求解使两侧曲率相等；
4. 直线↔曲线：按 Glyphs 的洞察处理——直线曲率为 0，故零曲率必须落在**曲线侧**
   （手柄取中点），并报告"空间是否足够"；
5. 尺寸沿用统一的 `nodeSize`，**不新增 size 设置**；指数 n 可在设置页调节，默认 **3**；
6. 可切换、可撤销、不破坏既有 corner/smooth 行为。

## 用户故事

- 我把曲线节点设为 squircle → 图标变超椭圆，过渡处曲率不再跳变。
- 我把直线与曲线的连接处设为 squircle → 生成平滑过渡，而不是生硬折线。

- ~~不做 Glyphs 的"导出时新增小灰点"可视化~~ —— **已被

- 不改变既有 smooth（眼形）与 corner（方形）行为；
- ~~不实现 Glyphs 的节点位移优化——默认解精确且**不需要移动节点**~~ —— **已被

  取代价更小者）。

## 验收标准

- squircle 节点显示**超椭圆**图标，无五角星；
- 曲线↔曲线：两侧曲率跳变降到机器精度（实测 3.125e-3 → **8.674e-19**）；
- 直线↔曲线：连接处曲率跳变为 0；
- 数学不可行时（拐点/反向弯曲）**不置标志、不改几何**（图标不得撒谎）；
- squircle 图标与角点方块**共用同一尺寸盒**（均为 `nodeSize`）；
- 设置页三色块尺寸一致；指数可调且**不随缩放变化**；
- e2e 全量回归通过；控制台零错误。
